# TGLD Secure Archive (TGLDS)

A secure, cross-platform encrypted archive format.

## Project objectives

- Custom .tgds archive format
- Authenticated encryption
- Argon2id key derivation
- Zstandard compression
- Encrypted metadata
- Android-first development
- Future Windows and Linux support

## Architecture

- Core engine: Rust
- Android application: Kotlin
- Build infrastructure: GitHub Actions
- Cloud infrastructure: Microsoft Azure when required

## Security

Security-first development.
No backdoors.
No plaintext storage of encryption keys.

## Status

Early development.
